## Ausgewählte Projekte

### [IT Asset & Maintenance Management System](https://github.com/ersin-simsek/it-asset-maintenance-system)

Eine Full-Stack-Anwendung, die auf meinen praktischen Erfahrungen in der IT-Abteilung der Mersin University basiert. Sie bildet den vollständigen Lebenszyklus von IT-Geräten und Wartungsvorgängen ab.

- Verwaltung von Gerätebestand, Status und Wartungshistorie
- Prozesse für Annahme, Übergabe, Reparatur, Rückgabe und Wiedereröffnung
- Erfassung von Ersatzteilen und Berechnung der Materialkosten
- Java 17, Spring Boot, React und PostgreSQL
- REST-API, Spring Data JPA und Eingabevalidierung
- 24 automatisierte Backend- und Frontend-Tests
- Swagger/OpenAPI-Dokumentation und Continuous Integration mit GitHub Actions

### [Student Course Management System](https://github.com/ersin-simsek/student-course-management-system)

Eine Oracle-APEX-Datenbankanwendung, die während meines Erasmus+-Studiums im Kurs Database Systems entwickelt wurde.

- Oracle SQL, PL/SQL und Oracle APEX
- Relationales Datenbankdesign und CRUD-Operationen
- Views, Trigger, Packages und Audit-Protokollierung
- Interaktive Berichte, Dashboard-Karten und Diagramme

### [MovieTracker](https://github.com/ersin-simsek/movie-tracker)

Eine responsive Anwendung zur Filmsuche und Verwaltung persönlicher Watchlists, entwickelt im Erasmus+-Kurs Web Applications Programming.

- HTML, CSS und JavaScript
- Suche, Filterung und Sortierung
- Watchlists, Bewertungen und persönliche Statistiken
- Lokale Profile und Speicherung im Browser
- [Live-Anwendung](https://ersin-simsek.github.io/movie-tracker/)
